## 6. 关键 automation 根因与避免复发

- 大仓库完整 checkout 过慢 → automation 使用 blobless + sparse。
- sparse checkout 必须包含根目录 `scenarios/` 和 `tracks/`，否则 validator 会误报 scenario registry missing。
- 新 SVG 加入 manifest 时必须先存在合法 `sha256` 字段（可先占位），再由 `refresh_submission_manifest.py` 写真实 hash。

- 正确修法：保留 canonical visual 的全部 required sections 和 `data-metric`，只在末尾追加 `id="v05-evidence"` 的 v0.5 evidence。
- 对 ready_for_review / formal package **禁止再次运行 scaffold-only `finalize_submission.py`**。
